# Layer Length Calculator

**Version:** 1.0.0  
**Category:** Vector

## Description

Calculate vector layer lengths using QGIS measurement settings and display results in multiple measurement units.

## Features

- Calculate selected or all feature lengths.
- Report measurements in metres, kilometres, feet and miles.
- Use project ellipsoid settings.
- Handle empty and invalid geometries.
- Display processing progress.
- Support cancellation between features.
- Provide detailed error reporting.

## Compatibility

Targeted QGIS versions: 3.28–3.99 and 4.x.

Qt5/PyQt5 and Qt6/PyQt6 compatibility.
