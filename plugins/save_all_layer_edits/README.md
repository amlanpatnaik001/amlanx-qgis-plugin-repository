# Save All Layer Edits

**Version:** 1.0.1  
**Author:** Amlan Patnaik

## Description

Save pending edits across all editable QGIS vector layers with one operation.

## Features

- Save pending edits across multiple vector layers.
- Keep editing mode enabled after successful commits.
- Display processing progress.
- Cancel processing between layer commits.
- Report individual layer commit failures.
- Continue processing other layers when one layer fails.
- Provide detailed error diagnostics through QGIS Log Messages.
- Prevent duplicate execution.

## Compatibility

- QGIS 3.28–3.99
- QGIS 4.x target
- PyQt5 / Qt5 compatibility
- PyQt6 / Qt6 compatibility
