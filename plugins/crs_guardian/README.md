# CRS Guardian

**Version:** 2.4.0  
**Category:** Vector  
**AMLAN-X Branded Release:** Amlan Patnaik

Professional CRS auditing, validation and safe reprojection for QGIS.

### Features
- Project-wide CRS diagnostics.
- Missing and suspicious CRS detection.
- Vector, raster and mesh CRS health checks.
- CRS assignment and reprojection.
- Batch CRS harmonization.
- CSV diagnostic reports.
- Activity history.
- Background processing and cancellation.

### Compatibility
QGIS 3.16–3.99 and QGIS 4.x compatibility target.
