# PG Exporter Pro

**Version:** 1.0.0  
**Category:** Database  
**Author:** Amlan Patnaik

## Description

Export selected PostgreSQL/PostGIS layers into a GeoPackage and create an offline QGIS project.

## Features

- Export selected PostgreSQL/PostGIS layers.
- Generate a consolidated GeoPackage.
- Preserve QML styles.
- Generate detailed export logs.
- Create an offline QGIS project (.qgz).
- Preserve project CRS, layer groups, order and visibility.
- Report individual layer export failures.

## Compatibility

- QGIS 3.22–3.99
- QGIS 4.x compatibility target
- PyQt5 / Qt5
- PyQt6 / Qt6

Runtime testing is required for each target QGIS installation.
